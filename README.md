Cosmic Code – Learn, Practice, Grow

About the Project

Cosmic Code is an Agentic AI-powered coding practice platform designed to help beginners improve their programming and problem-solving skills.

The platform recommends coding problems based on users' programming levels and difficulty preferences, helping learners follow a structured practice journey.

Key Features

- Personalized coding problem recommendations.
- Difficulty levels: Easy, Medium, and Hard.
- Adaptive practice based on solving performance.
- Progress tracking and achievements.
- Structured coding practice for beginners.

- HTML
- CSS
- JavaScript
